# My Personal AI Usage Rules

## Rule 1 - What I will never paste

- Passwords, API keys, tokens, private keys, and `.env` contents.
- Customer data or other confidential information.

## Rule 2 - What I will always verify before accepting

- AI-generated code and commands.
- Security claims and test results.
- Factual statements that affect decisions or production systems.

## Rule 3 - How I will record AI contributions

- Document material AI assistance in commits, pull requests, or project notes.
- Record what AI proposed and what I independently reviewed or changed.
