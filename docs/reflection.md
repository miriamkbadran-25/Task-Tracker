During the development process, I used different AI tools for different stages of the project. I started with ChatGPT, which I used mainly for prompt engineering, organizing my ideas, and creating the initial project documentation. It helped me write and refine the user stories and develop the Architecture Decision Record (ADR), ensuring that the requirements and technical decisions were clearly structured before starting implementation.

After defining the project direction, I moved to Cursor and VS Code for the coding phase. I used Cursor as an AI-assisted coding environment to help generate, understand, and modify code more efficiently while keeping the project structure in mind. I also used GitHub Copilot to support the frontend development, especially when creating and improving the user interface. Copilot helped speed up the process of writing UI components and handling repetitive frontend tasks.

AI specifically helped me during the coding and development phase since this is my first application. I am mainly a game developer and have limited experience working with frontend and backend development, or even using GitHub, which I had not worked with for a very long time. AI tools helped me understand unfamiliar concepts, write and modify code more efficiently, and guide me through the different stages of building a complete application.

However, there was also a moment where AI slowed down my progress. During development, ChatGPT became temporarily unavailable, and I relied on it frequently for guidance and problem-solving. This interruption affected my workflow because I had to spend additional time troubleshooting issues independently or searching for alternative solutions.

One place where my own review and testing changed the final result was while working on the filtering functionality. The initial implementation of the filters had some problems and did not always behave as expected. By manually reviewing the behavior, testing different scenarios, and analyzing the results, I identified the issues and adjusted the implementation. My review improved the final outcome by making the filtering feature more reliable and aligned with the expected user experience.

Overall, AI tools were valuable throughout the project by improving productivity, helping me learn new technologies, and assisting with development. However, they also showed the importance of human review, testing, and decision-making to ensure that the final product works correctly.
